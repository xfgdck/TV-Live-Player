一、设计总则
支持的交互方式：
1、遥控器交互按键：上、下、左、右、OK、返回、菜单。
2、键盘交互按键：上、下、左、右、Enter、Esc、菜单键/应用程序键。
3、触摸屏：滑动，点击，长按。

音量：由系统完全控制，软件内部无任何音量调节功能。

频道记忆：每次换台立刻保存当前频道ID；启动自动恢复上次频道并播放。

安装包：通用APK，兼容32/64位，Android 6 ~ 16。

界面层级：0级全屏直播 → 1级主菜单 → 2级或更多级子界面。

二、层级总览
层级	界面名称	说明
0级	全屏直播界面	默认只显示直播画面
1级	主菜单界面	左上角显示频道名称; 右侧三个按钮：设置、直播源管理、收藏
导航原则：按返回逐级退出；0级按返回提示二次确认退出。

三、0级 – 全屏直播界面
3.1 纯播放状态

界面

全屏视频

按键行为

按键	操作
上 / 下	切换至上/下一个频道。
左 / 右	进入分类频道选择状态（见3.2）。
OK	暂停视频，并打开1级主菜单。
菜单	不暂停视频，直接打开1级主菜单（视频继续播放）。
返回	屏幕显示“再按一次返回键退出”。3秒内再按返回退出应用；其他按键或超时则取消提示。

3.2 分类频道选择状态
触发：纯播放状态按左/右。

界面

底部半透明横向分类标签栏，左右排列，当前分类高亮。

标签栏上方显示该分类频道列表，竖向排列，聚焦频道显示边框，选中频道高亮。

系统内置“我的收藏”分类，同样出现在标签栏。

频道条目不显示收藏图标，也没有任何收藏操作入口。

按键

按键	行为
左 / 右	切换分类，频道列表刷新，焦点停在第一个频道。
上 / 下	移动频道焦点。
OK	跳转至焦点频道，播放并保存，返回纯播放状态。
返回	取消选择，返回纯播放状态，继续播放原频道。


四、1级 – 主菜单界面（关键调整）
进入方式

从0级纯播放状态按 OK（视频暂停）或 菜单（视频继续播放）进入。

界面元素

屏幕右侧三个按钮从上到下依次为：

设置

节目编辑

收藏

“收藏”按钮显示当前播放频道的收藏状态图标：

☆ 空心：未收藏

★ 实心：已收藏

焦点默认在“设置”。

按键行为

按键	操作
上 / 下	在按钮间移动焦点。
OK（焦点在设置/节目编辑）	进入对应的子界面。
OK（焦点在收藏按钮）	切换当前频道收藏状态，不弹出任何界面。
• 若未收藏 → 变为已收藏，图标切换为★，提示已收藏，频道加入“我的收藏”分类。
• 若已收藏 → 变为未收藏，图标切换为☆，提示已取消收藏，频道从“我的收藏”分类移除。
返回	关闭主菜单，返回0级纯播放状态。若由OK进入，返回后自动继续播放；若由菜单进入则保持原播放状态。
菜单	等同于返回。
设计说明

收藏功能仅限此按钮操作，其他地方（0级分类选择、节目编辑非“我的收藏”分类）不再提供任何收藏/取消收藏入口。

按钮的图标实时反映当前播放频道的收藏状态，进入菜单时即更新。
